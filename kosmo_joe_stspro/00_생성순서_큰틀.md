# kosmo_joe_stspro 생성순서 큰 틀

이 문서는 `kosmo_joe_stspro` 프로젝트를 만들 때 어떤 파일을 먼저 만들고, Controller에서 받은 요청이 어떤 JSP로 이동하는지 정리한 표입니다.

## 1. 전체 생성순서

| 순서 | 파일 | 먼저 알아야 할 역할 |
|---|---|---|
| (1) | `HomeController.java` | `/` 첫 화면 요청을 `index.jsp`로 보냄 |
| (2) | `MemberController.java` | `/member/mypage`, `/member/login`, `/member/join` 요청을 각각 JSP로 보냄 |
| (3) | `NoticeDTO.java` | `variable`, `number` 데이터를 담는 상자 타입 |
| (4) | `NoticeService.java` | DTO 객체를 만들고 실제 Java 데이터를 넣음 |
| (5) | `NoticeController.java` | Service 데이터를 받아 `Model`에 담고 JSP로 보냄 |
| (6) | `QnaController.java` | `/qna/list`, `/board/add`, `/board/detail` 요청을 JSP로 보냄 |
| (7) | `index.jsp` | `HomeController.java` 15번째 줄 `return "index"`로 열림 |
| (8) | `member/mypage.jsp` | `MemberController.java` 15번째 줄 `return "member/mypage"`로 열림 |
| (9) | `users/login.jsp` | `MemberController.java` 23번째 줄 `return "users/login"`로 열림 |
| (10) | `users/join.jsp` | `MemberController.java` 31번째 줄 `return "users/join"`로 열림 |
| (11) | `notice/list.jsp` | `NoticeController.java` 29번째 줄 `return "notice/list"`로 열림 |
| (12) | `notice/detail.jsp` | `NoticeController.java` 49번째 줄 `return "notice/detail"`로 열림 |
| (13) | `notice/add.jsp` | `NoticeController.java` 37번째 줄 `return "notice/add"`로 열림 |
| (14) | `qna/list.jsp` | `QnaController.java` 15번째 줄 `return "qna/list"`로 열림 |
| (15) | `board/add.jsp` | `QnaController.java` 23번째 줄 `return "board/add"`로 열림 |

## 2. Notice 목록 데이터 흐름

```text
NoticeDTO(3)
-> NoticeService(4)
-> NoticeController(5)
-> notice/list.jsp(11)
-> 브라우저 화면
```

| 위치 | 코드 | 의미 |
|---|---|---|
| `NoticeDTO.java` 13번째 줄 | `private String variable;` | 문자열 데이터를 담는 멤버변수 |
| `NoticeDTO.java` 15번째 줄 | `private Integer number;` | 숫자 데이터를 담는 멤버변수 |
| `NoticeService.java` 15번째 줄 | `NoticeDTO dto = new NoticeDTO();` | DTO 상자 하나 생성 |
| `NoticeService.java` 17번째 줄 | `dto.setVariable("DTO");` | 첫 번째 DTO에 문자열 저장 |
| `NoticeService.java` 25번째 줄 | `List<NoticeDTO> dat = new ArrayList<>();` | 여러 DTO를 담을 목록 생성 |
| `NoticeService.java` 27번째 줄 | `dat.add(dto);` | 목록에 첫 번째 DTO 추가 |
| `NoticeService.java` 29번째 줄 | `dat.add(dab);` | 목록에 두 번째 DTO 추가 |
| `NoticeService.java` 31번째 줄 | `return dat;` | `List<NoticeDTO>`를 Controller로 반환 |
| `NoticeController.java` 25번째 줄 | `List<NoticeDTO> dto = output.list();` | Service가 준 목록을 Controller 변수로 받음 |
| `NoticeController.java` 27번째 줄 | `model.addAttribute("output", dto);` | JSP에서 `output`이라는 이름으로 쓰게 Model에 담음 |
| `notice/list.jsp` 21번째 줄 | `<c:forEach var="notice" items="${output}">` | `output` 목록을 하나씩 꺼냄 |
| `notice/list.jsp` 23번째 줄 | `${notice.variable} / ${notice.number}` | DTO의 값을 화면에 출력 |

## 3. Notice 상세 데이터 흐름

```text
NoticeDTO(3)
-> NoticeService.detail()
-> NoticeController.detail()
-> notice/detail.jsp(12)
-> 브라우저 화면
```

| 위치 | 코드 | 의미 |
|---|---|---|
| `NoticeService.java` 35번째 줄 | `public NoticeDTO detail()` | DTO 하나를 반환하는 상세 메서드 |
| `NoticeService.java` 37번째 줄 | `NoticeDTO dto = new NoticeDTO();` | 상세용 DTO 상자 생성 |
| `NoticeService.java` 39번째 줄 | `dto.setVariable("DTODTODTO");` | 상세용 문자열 저장 |
| `NoticeService.java` 41번째 줄 | `return dto;` | DTO 하나를 Controller로 반환 |
| `NoticeController.java` 45번째 줄 | `NoticeDTO dto = output.detail();` | Service가 준 DTO 하나를 받음 |
| `NoticeController.java` 47번째 줄 | `model.addAttribute("input", dto);` | JSP에서 `input` 이름으로 쓰게 Model에 담음 |
| `notice/detail.jsp` 19번째 줄 | `${input.variable}` | `NoticeDTO`의 `variable` 값을 출력 |
| `notice/detail.jsp` 21번째 줄 | `${input.number}` | `NoticeDTO`의 `number` 값을 출력 |

## 4. Model model 문법 이해

```java
public String list(Model model)
```

| 부분 | 뜻 |
|---|---|
| `Model` | 데이터 타입. Spring이 제공하는 JSP 전달 상자 타입 |
| `model` | 변수명. 메서드 안에서 실제로 사용하는 이름 |
| 대문자 `Model` | 클래스/인터페이스 타입 이름은 보통 대문자로 시작 |
| 소문자 `model` | 변수명/메서드명은 보통 소문자로 시작 |

쉽게 말하면:

```text
Model model
= Model 타입의 상자를 model이라는 이름으로 쓰겠다.
```

## 5. model.addAttribute 뜻

```java
model.addAttribute("output", dto);
```

| 부분 | 뜻 |
|---|---|
| `model` | JSP로 데이터를 보내는 Model 변수 |
| `.` | 왼쪽 객체 안에 있는 기능이나 값을 사용한다는 뜻 |
| `addAttribute()` | Model 안에 데이터를 담는 메서드 |
| `"output"` | JSP에서 꺼낼 때 사용할 이름표 |
| `dto` | 실제로 JSP에 보내는 Java 데이터 |

즉:

```text
dto 데이터를 output이라는 이름표로 Model에 담아서 JSP로 보내줘.
```

## 7. 지금 외울 것

```text
DTO는 데이터를 담는다.
Service는 DTO에 데이터를 넣는다.
Controller는 Service를 호출해서 Model에 담는다.
JSP는 Model 이름으로 데이터를 꺼내 화면에 출력한다.
```
