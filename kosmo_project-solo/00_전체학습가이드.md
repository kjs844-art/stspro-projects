---

## 프로젝트 아이디어 출처

| 참고 프로젝트 | 가져온 개념 |
|---|---|
| `kosmo_bio_stock` | 외부 API → DTO → Service → Controller → JSP 흐름, 검색 기능 |

## 전체 파일 생성 순서 한눈에 보기

```
[Phase 1] 뼈대
  (1) build.gradle           → 이미 완성됨 (의존성 설정)
  (2) application.properties → 이미 완성됨 (DB, JSP 경로, 포트)
  (3) Application.java       → 이미 완성됨 (Spring Boot 시작점)
  (4) HomeController.java    → "/" URL을 index.jsp로 연결
  (5) index.jsp              → 첫 화면 (대시보드 메인 페이지)

[Phase 2] 외부 API - 주식 데이터
  (6)  StockDTO.java         → 주식 데이터를 담는 상자 정의
  (7)  StockService.java     → AlphaVantage API 호출 → DTO에 담기
  (8)  StockController.java  → URL 요청 → Service → Model → JSP
  (9)  stock/list.jsp        → 주식 목록 화면

[Phase 3] 외부 API - 임상시험 데이터
  (10) ClinicalDTO.java      → 임상시험 데이터를 담는 상자 정의
  (11) ClinicalService.java  → ClinicalTrials.gov API 호출 → DTO에 담기
  (12) ClinicalController.java → URL 요청 → Service → Model → JSP
  (13) clinical/list.jsp     → 임상시험 목록 화면

[Phase 4] DB 연결 - 관심종목 저장
  (14) WatchlistDTO.java     → DB에서 꺼낸 관심종목 데이터를 담는 상자
  (15) WatchlistMapper.java  → MyBatis 인터페이스 (SQL 메서드 선언)
  (16) WatchlistMapper.xml   → 실제 SQL 쿼리 작성
  (17) WatchlistService.java → Mapper 호출 → 비즈니스 로직 처리
  (18) WatchlistController.java → CRUD 요청 처리
  (19) watchlist/list.jsp    → 관심종목 목록 화면
  (20) watchlist/add.jsp     → 관심종목 추가 화면

[Phase 5] 회원 기능
  (21) MemberDTO.java        → 회원 데이터를 담는 상자
  (22) MemberMapper.java     → 회원 SQL 메서드 선언
  (23) MemberMapper.xml      → 회원 SQL 쿼리 (INSERT, SELECT)
  (24) MemberService.java    → 로그인 검증, 회원가입 처리
  (25) MemberController.java → 로그인/가입/마이페이지 요청 처리
  (26) users/login.jsp       → 로그인 화면
  (27) users/join.jsp        → 회원가입 화면
  (28) member/mypage.jsp     → 마이페이지 화면

[Phase 6] 완성 & 배포
  (29) SecurityConfig.java   → Spring Security 로그인 설정
  (30) 배포 설정             → Render / Railway / AWS 배포
```

## 핵심 흐름 공식 (이것만 외우면 Spring Boot 이해 완성)

```
브라우저 URL 입력
    ↓
Controller (요청을 받는 교통경찰)
    ↓
Service (실제 일을 하는 사무원)
    ↓
Mapper/API (DB에서 꺼내거나 외부 API 호출)
    ↓
DTO (데이터를 담아 나르는 택배상자)
    ↓
Model (JSP에 전달할 데이터 보관함)
    ↓
JSP (브라우저 화면으로 출력)
```

---

## Phase별 학습 목표

| Phase | 핵심 개념 | 완료 후 실력 |
|---|---|---|
| Phase 1 | Spring Boot 구조, @Controller, @GetMapping, JSP 연결 | 입문 완성 |
| Phase 2 | DTO, @Service, RestTemplate, 외부 API 호출 | 입문→초급 |
| Phase 3 | 여러 API 동시 연동, @RequestParam 검색 | 초급 |
| Phase 4 | MyBatis, DB CRUD, Mapper 인터페이스, XML SQL | 초급→중급 |
| Phase 5 | 세션, 로그인 검증, 회원 CRUD, 폼 전송(POST) | 중급 |
| Phase 6 | Spring Security, 배포, 실제 서비스 경험 | 중급→고급 |

## 파일 위치 규칙 (패키지 구조)

```
src/main/
├── java/com/joe/app/
│   ├── home/              ← HomeController.java
│   ├── stock/             ← StockDTO, StockService, StockController
│   ├── clinical/          ← ClinicalDTO, ClinicalService, ClinicalController
│   ├── watchlist/         ← Watchlist 관련 전체 (DTO, Mapper, Service, Controller)
│   └── member/            ← Member 관련 전체
└── webapp/
    └── WEB-INF/views/
        ├── index.jsp       ← 메인 화면
        ├── stock/          ← 주식 관련 JSP
        ├── clinical/       ← 임상시험 관련 JSP
        ├── watchlist/      ← 관심종목 관련 JSP
        ├── users/          ← login.jsp, join.jsp
        └── member/         ← mypage.jsp
```

## 학습 방법

1. 이 가이드 파일을 항상 열어두고 현재 위치를 확인한다
2. 각 파일을 열면 주석으로 "무엇을", "왜", "어떻게" 작성할지 설명되어 있다
3. 주석을 읽고 직접 코드를 작성한다 (복붙 금지, 타이핑으로 익힌다)
4. 작성 후 서버를 실행해서 브라우저로 확인한다
5. 막히면 선생님(Claude)에게 물어본다
