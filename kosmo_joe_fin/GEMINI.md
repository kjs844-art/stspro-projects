# Gemini CLI Handoff - kosmo_joe_fin

이 프로젝트는 사용자의 STS/Spring Boot 금융 포트폴리오 프로젝트입니다.

## 시작 전에 읽기

```text
AGENTS.md
START_HERE_RUN_THIS_PROJECT.md
KOSMO_JOE_FIN_PROGRESS_2026-05-21.md
docs/ai-collaboration-mcp-setup.md
```

## 작업 규칙

- 한국어로 설명합니다.
- 사용자는 초보자이므로 한 번에 한 단계씩 안내합니다.
- 파일 수정 전에는 어떤 파일을 왜 고치는지 짧게 말합니다.
- 기존 변경사항을 되돌리지 않습니다.
- `.env`, `.mcp.json`, `opencode.jsonc`, `.gemini/settings.json`, `.antigravity/` 안의 비밀값은 읽거나 커밋하지 않습니다.

## 현재 프로젝트

```text
C:\Users\USER\Desktop\STSPRO\프로젝트 모음\kosmo_joe_fin
http://localhost:18085
```

```text

```
