# Antigravity Handoff - kosmo_joe_fin

Antigravity에서 이 프로젝트를 열 때 참고하는 협업 메모입니다.

## 핵심

```text
프로젝트: C:\Users\USER\Desktop\STSPRO\프로젝트 모음\kosmo_joe_fin
실행 주소: http://localhost:18085
공통 규칙: AGENTS.md
Gemini 규칙: GEMINI.md
Claude 규칙: CLAUDE.md
```

## Antigravity 작업 방식

- 먼저 `AGENTS.md`를 읽습니다.
- 큰 리팩토링보다 작은 기능 하나를 맡깁니다.
- 변경 후에는 어떤 파일이 바뀌었는지 요약합니다.
- STS/Gradle 빌드 산출물 잠금 문제를 코드 오류로 오해하지 않습니다.

## MCP 설정 위치 참고

Antigravity의 MCP 설정은 보통 사용자 전역 설정에 둡니다.

```text
C:\Users\USER\.gemini\antigravity\mcp_config.json
```

프로젝트에는 실제 키가 들어간 파일을 두지 않고,
아래 예시 파일만 참고합니다.

```text
docs/antigravity-mcp.example.json
```
