# kosmo_bio_stock 4단계 검색 기능 흐름

목표: `/radar/list` 화면에서 검색어를 입력하면, Controller가 검색어를 받고 Service가 목록을 필터링한 뒤 JSP에 결과를 출력합니다.

---

## 현재 완료 범위

| 단계 | 내용 | 상태 |
|---|---|---|
| 1단계 | 프로젝트 뼈대 만들기 | 완료 |
| 2단계 | `/radar/list` 기본 화면 만들기 | 완료 |
| 3단계 | `Controller -> Service -> DTO -> Model -> JSP` 흐름 만들기 | 완료 |
| 4단계 | 검색어로 데이터 필터링하기 | 완료 |

---

## 전체 흐름

```text
브라우저 검색창
-> /radar/list?keyword=FDA
-> BioRadarController.list()
-> BioRadarService.findSignals(keyword)
-> BioSignalDTO 목록 필터링
-> model.addAttribute("signals", signals)
-> radar/list.jsp
-> 화면 출력
```

## 파일별 역할

| 파일 | 역할 |
|---|---|
| `BioSignalDTO.java` | 바이오/주식 신호 데이터 하나를 담는 상자 |
| `BioRadarService.java` | 샘플 데이터를 만들고 검색어와 맞는 데이터만 골라냄 |
| `BioRadarController.java` | URL 요청과 검색어를 받고, Service 결과를 JSP로 보냄 |
| `radar/list.jsp` | 검색창과 결과 표를 화면에 보여줌 |

## 핵심 코드 연결

### 1. JSP 검색창

```jsp
<input type="text" name="keyword">
```

`name="keyword"` 때문에 검색어가 Controller의 `String keyword`로 들어갑니다.

### 2. Controller에서 검색어 받기

```java
public String list(@RequestParam(required = false) String keyword, Model model)
```

`@RequestParam`은 URL의 `keyword` 값을 Java 변수로 받는 역할입니다.

### 3. Service에 검색어 넘기기

```java
List<BioSignalDTO> signals = bioRadarService.findSignals(searchKeyword);
```

Controller가 직접 검색하지 않고, Service에게 검색 작업을 맡깁니다.

### 4. Service에서 필터링하기

```java
if (text.toLowerCase().contains(lowerKeyword)) {
    filteredSignals.add(signal);
}
```

DTO 안의 글자 데이터에 검색어가 포함되어 있으면 결과 목록에 넣습니다.

### 5. Model에 담아서 JSP로 보내기

```java
model.addAttribute("signals", signals);
model.addAttribute("keyword", searchKeyword);
model.addAttribute("resultCount", signals.size());
```

JSP는 `${signals}`, `${keyword}`, `${resultCount}` 이름으로 데이터를 꺼냅니다.

### 6. JSP에서 반복 출력하기

```jsp
<c:forEach var="signal" items="${signals}">
```

`signals` 목록에서 DTO를 하나씩 꺼내 `signal`이라는 이름으로 사용합니다.
